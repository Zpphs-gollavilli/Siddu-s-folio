                            🚀 THE 6 STEPS
════════════════════════════════════════════════════════════════════════════════

    Step 1️⃣  Push to GitHub
             $ git add .
             $ git commit -m "Deploy configuration"
             $ git push origin host-websocket-server
             Time: 1 minute

    Step 2️⃣  Deploy Backend to Railway
             • Visit: https://railway.app
             • Create new project from GitHub
             • Select repository & /backend folder
             • Wait for green checkmark ✓
             • Save your Railway domain
             Time: 5 minutes

    Step 3️⃣  Update Frontend Config
             • Edit: Siddu-S-3D-World/.env.production
             • Add Railway domain: VITE_SERVER_URL=wss://your-domain
             • Git push again
             Time: 2 minutes

    Step 4️⃣  Deploy Frontend to Vercel
             • Visit: https://vercel.com
             • Create new project from GitHub
             • Set root: ./Siddu-S-3D-World
             • Add env variable VITE_SERVER_URL
             • Deploy
             Time: 5 minutes

    Step 5️⃣  Test Your Deployment
             • Open your Vercel URL
             • Check WebSocket connects (DevTools F12)
             • Verify 3D world loads
             Time: 2 minutes

    Step 6️⃣  Share Your Portfolio! 🎉
             Your URL: https://your-project.vercel.app
