QUICK COMMAND REFERENCE:

Step 1: Git Push
  $ git add .
  $ git commit -m "Deploy: Add Railway and Vercel config"
  $ git push origin host-websocket-server

Step 2: Railway Dashboard
  https://railway.app/dashboard
  → Create New → Deploy from GitHub
  → Select: Zpphs-gollavilli/Siddu-s-folio
  → Root: /backend
  → Wait → Copy domain

Step 3: Update Frontend
  Edit: Siddu-S-3D-World/.env.production
  VITE_SERVER_URL=wss://YOUR-RAILWAY-DOMAIN

  $ git add Siddu-S-3D-World/.env.production
  $ git commit -m "Update: Production WebSocket URL"
  $ git push origin host-websocket-server

Step 4: Vercel Dashboard
  https://vercel.com/dashboard
  → Add New → Project
  → Import Git Repo
  → Root: ./Siddu-S-3D-World
  → Env: VITE_SERVER_URL=wss://YOUR-RAILWAY-DOMAIN
  → Deploy

Step 5: Test & Share!
  Open: https://YOUR-VERCEL-DOMAIN.vercel.app
